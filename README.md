# prosit-4-collaboration

Il s'agit d'un repo pour le prosit 4

&#x20;Objectif

Apprendre à utiliser Git et GitHub pour mieux coordonner le travail en équipe.



&#x20;Rôles dans le scénario

&#x20;Alex : chef de projet.

&#x20;Léa : développeuse front-end.

&#x20;Max : développeur back-end.

&#x20;Chrislaine : contributrice occasionnelle.



&#x20;Règles de collaboration

&#x20;Créer une branche pour chaque tâche.

&#x20;Faire des commits avec des messages clairs.

&#x20;Envoyer sa branche sur GitHub.

&#x20;Ouvrir une pull request pour proposer ses modifications.

&#x20;Faire relire les modifications par un autre membre avant la fusion.

&#x20;Résoudre les conflits et vérifier le résultat avant de fusionner.
